## Description

This activity demonstrates how to set up a Node.js project, install npm packages, and use the package.json file.

## Files

- `index.js` - Main JavaScript file that displays my name and activity information.
- `package.json` - Contains the project information, scripts, and installed packages.
- `package-lock.json` - Records the exact versions of installed packages.
- `N1_answers.docx` - Contains the written answers for this activity.
- `screenshots/` - Contains screenshots of the setup and program output.

## How to Run

1. Open the terminal inside the `n1-setup` folder.
2. Run `npm install` to install the required packages.
3. Run `npm start` to execute the program.
